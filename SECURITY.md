# Security Policy

## Supported Versions

Only the latest deployed version on the `master` branch receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| master  | :white_check_mark: |

## Reporting a Vulnerability

Do not open a public GitHub issue for security vulnerabilities.

Send vulnerability details by email to `hello@heantee.foo`. Include these details in your report:

- The affected URL or file path
- Steps to reproduce the issue
- Potential security impact

You will receive an acknowledgment within 72 hours.
